# auth_app

Aplicación móvil en React Native. Por ahora es solo un cascarón y no implementa funcionalidades.

## Requisitos

- Node.js `>= 22.11.0`
- Android: Android SDK y Java 21
- iOS: Xcode y CocoaPods (macOS)

## Ejecución

```bash
npm install
npm start
```

En otra terminal, inicia la app:

```bash
npm run android
# o
npm run ios
```
